### 1.4. Structured Data (Мікророзмітка Schema.org / JSON-LD)

- **Поточний стан (`index.html:11-33`):** присутній блок `@type: "Product"` з `AggregateRating` та `Offer`.
- **Помилки та проблеми:**
  1. **Невідповідність типу:** Для SaaS-продукту (хмарного ПЗ) значно точнішим є `@type: "SoftwareApplication"` або `@type: "WebApplication"` із властивістю `applicationCategory: "BusinessApplication"` та `operatingSystem: "Web"`.
  2. **Вимоги валідатора Schema.org / Google Rich Results:**
     - У типі `Product` Google вимагає наявність поля `image` (зараз відсутнє).
     - Рейтинг `AggregateRating` вказано (`ratingValue: 4.9`, `reviewCount: 1284`), але на сторінці немає розмічених відгуків (`review`), що може призвести до санкцій за некоректну розмітку відгуків.
  3. **Відсутня розмітка організації:** Бажано додати окремий блок `Organization` (назва, логотип, соцмережі) або `FAQPage` для блоку з питаннями.

### 1.5. Performance & Core Web Vitals (Причини низьких оцінок у `measurement.txt`)

- **LCP (Largest Contentful Paint) = 14.8 с (Норма <= 2.5 с):**
  - Головний фактор — файл `img/hero.jpg` важить **2.78 МБ**! Це велетенське нестиснене растрове зображення.
  - Зображення не має атрибутів `width` і `height`, не оптимізоване у WebP/AVIF та не має `fetchpriority="high"`.
  - Скрипт `js/main.js` підключено у `<head>` без `defer` або `async` (блокує парсинг DOM).
- **CLS (Cumulative Layout Shift) = 0.13 (Норма <= 0.1):**
  - У `js/main.js` (рядки 71-78) через 800 мс після завантаження в початок `body` примусово вставляється блок `.promo`, що зсуває весь контент сторінки вниз.
- **TBT (Total Blocking Time) = 110-470 мс:**
  - У функції `startSignup()` в `main.js` (рядки 20-24) штучно вбудовано цикл затримки на 300 мс (`while (Date.now() - started < 300)`), який блокує основний потік браузера при кліку на CTA.

## 2. Друга сторінка (`about.html`)

### 2.1. Accessibility (Доступність)

1. **Невидимий фокус:** Успадковує критичну проблему `:focus { outline: none; }` з файлу `css/styles.css`.
2. **Мертве меню навігації (`about.html:17-20`):**
   - Елементи `<div class="nav-item">Product</div>`, `Pricing`, `FAQ`, `Trial` не мають ані тегів `<a>`, ані атрибутів `data-target`. Вони візуально виглядають як пункти меню, але абсолютно статичні й недоступні для кліку чи клавіатури.
   - Має бути: `<a href="index.html#features" class="nav-item">Product</a>` тощо.
3. **Кнопка в шапці (`about.html:26-33`):**
   - Присутній надлишковий атрибут `role="button"` на нативному елементі `<button>`.
   - Задано антипатерн доступності: `aria-label="Get started button"`. Скрінрідери самі додають тип елемента, тому вони читають це як: _"Get started button, кнопка"_. Правильно: або не ставити `aria-label` (бо всередині вже є текст "Get started"), або написати `aria-label="Get started with FlowTask"`.
4. **Контрастність тексту:**
   - Параграфи `<p class="muted">` та `<p class="soft">` (рядки 42, 77) використовують кольори `#939ba7` та `#717985`, що мають занижений контраст на світлому фоні.
5. **Порожні посилання у футері:**
   - `<a href="#">Careers</a>`, `<a href="#">Docs</a>` тощо.

### 2.2. SEO та метадані

1. **Відсутність `lang` у тегу `<html>` (`about.html:2`):**
   - `<html >` без атрибута мови (потрібно `lang="en"`).
2. **Дубльований і неінформативний `<title>` (`about.html:6`):**
   - Вказано просто `<title>FlowTask</title>`. Це повний дублікат заголовка головної сторінки.
   - Пошуковики карають за однакові тайтли на різних сторінках сайту.
   - Рекомендовано: `<title>About Us — FlowTask Team, Mission & Story</title>`.
3. **Відсутній `<meta name="description">`:**
   - Сторінка не має мета-опису для пошукової видачі.
4. **Відсутній канонічний тег:**
   - Немає `<link rel="canonical" href="https://yourdomain.com/about.html">`.
5. **Рендер-блокуючий скрипт:**
   - `<script src="js/main.js"></script>` завантажується у `<head>` синхронно, без атрибута `defer`.

### 2.3. Open Graph та Structured Data

1. **Open Graph / Twitter Cards:** повністю відсутні.
2. **Structured Data (Schema.org):**
   - На сторінці `about.html` зовсім немає мікророзмітки.
   - Ідеально підходить тип `@type: "AboutPage"` у зв'язці з `@type: "Organization"`, де зазначено контактні дані (`hello@flowtask.example`), розташування команди (Київ, Лісабон, Торонто) та юридичну інформацію.
